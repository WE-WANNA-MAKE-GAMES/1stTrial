# For Developing

## Branch
* main
* develop
* feature/〇〇 (人名)
* 各々のfeature/〇〇内で作業し、できたものをdevelopにpull request

## Commit
Folloings are some example
* feat: プレイヤー移動を追加
* fix: ジャンプバグ修正
* refactor: EnemyManagerを整理
* docs: README更新

## Rules
* mainへ直接push禁止
* Pull Request必須
* レビュー1人
* 作業前はgit pull
* Issueを作ってから作業
